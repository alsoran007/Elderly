## 1. 核心结论

我实测了全部 7 个队列的死亡日期可得性与波次结构。**结果与预期相反**：

> **CHARLS（开发集）的结局时间精度是 7 个队列里最差的，其余 6 个大多有精确死亡日期。而 ELSA 存在一个更严重的问题——它的死亡随访止于 2012 年。**

| 队列 | 死亡日期精度 | 覆盖率 | 随访止于 | 4 年窗口可行性 |
|---|---|---|---|---|
| **CHARLS** | 波次级（2015 起无日期） | 日期仅 2013 波 | 2020 | ✅ 2011→2015 |
| **CLHLS** | **validated 年/月/日** | **98.6%** | 2018 | ✅ 2011→2015 |

## 2. 🔴 ELSA 的硬约束（需你决策）

### 2.1 实测证据

Harmonized ELSA G.3 的 `iwstat` 变量按波次统计（`5 = died this wave`，`6 = died prev wave`）：

| 波次 | 年份 | code 5（本波新死亡） | code 6（累计已故） |
|---|---|---|---|
| w1 | 2002 | 0 | 0 |
| w2 | 2004 | 508 | 0 |
| w3 | 2006 | 529 | 508 |
| w4 | 2008 | 589 | 1,037 |
| w5 | 2010 | 608 | 1,626 |
| w6 | 2012 | 518 | 2,234 |
| **w7** | **2014** | **0** | **2,752** |
| **w8** | **2016** | **0** | 2,752 |
| **w9** | **2018** | **0** | 2,752 |

**w7 起新死亡全为 0，累计数冻结在 2,752。** EOL 文件 `h_elsa_eol_a2.dta` 的死亡年份范围也只到 **2002–2012**（980 条记录，Version A.2）。

主文件 `radyear` 同样只覆盖 2000–2012，仅 849 条非缺失。

### 2.2 这意味着什么

ELSA 的死亡随访实际到 **2012 年（w6）**。若基线定在 2012（原计划），则：

- 4 年窗口 = 2012→2016，而 **2012 年后无任何死亡记录**
- 事件数 = **0**
- **ELSA 无法作为验证队列**

### 2.3 决策：ELSA 移出 Aim 3（选项 C，2026-07-27 冻结）

**✅ 已决策：ELSA 不作为 Aim 3 的验证队列。Aim 3 主分析使用 HRS + SHARE + MHAS。**

**决策依据：**

1. **数据硬约束。** Harmonized ELSA G.3 的死亡随访止于 2012 年。若基线定在 2012（与其他队列对齐所需），4 年窗口内事件数为 0，队列在技术上不可用。
2. **欧洲代表性不依赖 ELSA。** SHARE 覆盖 27 个欧洲国家，其中包含与英国医疗制度、收入水平相近的西欧、北欧国家。Aim 3 的"欧洲外部验证"由 SHARE 独立支撑，并可通过 leave-one-country-out 得到 20+ 个国家层面的性能分布——这比单一英国队列的信息量更大。
3. **换取基线时期对齐。** 移出 ELSA 后，其余 6 个队列基线全部落在 2011–2012 年区间。这消除了时期效应（医疗水平、死亡率长期趋势）对"跨队列性能差异"的混杂，使 H4 的归因分解（事件率 / 分布 / 测量 / 残差）更加干净。若保留 ELSA 并使用 2006 基线，则与 CHARLS 相差 5 年，任何 ELSA 上的性能下降都无法区分是"跨文化"还是"跨时期"造成的。
4. **成本收益不成比例。** 为纳入一个队列而引入一个无法排除的系统性混杂，代价高于收益。

**论文中的表述（建议）：**

> ELSA was considered but not included as an external validation cohort. In the Harmonized ELSA (Version G.3) data available to us, mortality follow-up is complete only through 2012, which precludes constructing a 4-year outcome window aligned with the 2011–2012 baselines used in the other cohorts. Because SHARE already provides external validation across 27 European countries, including several with health systems comparable to England, we prioritised baseline-period alignment over adding a further single-country European cohort.

**Limitations 中需承认的一点：**

> 我们的欧洲验证依赖 SHARE，未包含英国。ELSA 与 SHARE 在抽样与测量协议上存在差异，因此本研究的结论不能自动外推到 ELSA 类型的队列。

### 2.4 ELSA 的保留用途（不进主分析）

ELSA 数据仍留在项目中，但仅用于两个非关键路径的用途：

1. **变量 harmonization 的交叉参照。** `h_elsa_g3.dta` 有 11,779 个 Gateway 标准变量，可用于核对我们对 CHARLS/KLoSA 自建变量的编码是否符合 Gateway 惯例。
2. **可选的补充分析（若期刊审稿要求）。** 若审稿人质疑欧洲代表性，可补做「ELSA 2006 基线 → 2010」的额外验证，并明确标注基线年份与其他队列错配 5 年。**此分析不预先规定，仅作为应对审稿的备选。**

### 3.2 CLHLS（Aim 1 验证集）

| 项目 | 值 |
|---|---|
| 基线 | 2011/2012（跨两年，实测 2011=7,328、2012=2,437） |
| 风险期 | 期1: 基线→2014；期2: 2014→2018 |
| 4 年窗口 | 基线→2014 波 + 部分 2018 波 |
| 死亡日期 | `d14vyear/month/day`、`d18vyear/month/day`，**98.6% 可用** |
| 60+ 事件数 | 4 年内约 4,020（需按新窗口重算） |

⚠️ **CLHLS 的波次间隔与 CHARLS 不同**：CLHLS 是 2011→2014（3 年）→2018（4 年），CHARLS 是 2011→2013（2 年）→2015（2 年）。

**处理方式**：CLHLS 有精确死亡日期，因此可以**直接用日期切出「基线后 4 年内」**，不必受波次结构限制。这比 CHARLS 更精确，但为可比性，两者都归入「4 年死亡」这一结局定义。

**这个不对称需要在论文中说明**：开发集用离散波次近似 4 年，验证集用精确日期切 4 年。可作为一项敏感性分析（在 CLHLS 上也用波次近似，检验结论是否变化）。

**结论：全部队列远超外部验证的 ≥100 事件门槛。** 最小的是 CHARLS 开发集（785），最大的是 SHARE（6,287）。

**KLoSA 的事件分布值得注意**（按 exit 波统计 2012–2016 的死亡）：

## 5. 一个方法学不对称（需在论文中说明）

| | 开发集 CHARLS | 验证集（其余） |
|---|---|---|
| 时间精度 | 只能波次级 | 多数有精确日期 |
| 4 年窗口的实现 | 期1+期2 近似 | 可用日期精确切分 |

**这不影响外部验证的有效性**（模型的输入是基线预测因子，输出是 4 年死亡概率；两边的结局定义在实质上一致），但需要：

1. 在 Methods 中明确说明两种实现方式
2. 做一项敏感性分析：在有精确日期的队列上**也用波次近似**，检验结论是否变化
3. 不得声称"所有队列的随访时间精确到日"
