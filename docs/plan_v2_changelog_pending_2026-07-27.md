## B. 需要补入的新增内容（v1 完全没有）

| # | 内容 | 为什么必须写进计划书 | 依据 |
|---|---|---|---|
| B1 | **CHARLS ID 桥接规则** `householdID + "0" + id[-2:]` | 不做这步跨波匹配为 0，整个随访构建失败。v1 完全没意识到这个问题 | `charls_outcome_plan_v2` §3.1 |
| B2 | **CHARLS 2015/2018 无死亡日期** | 这是改用离散时间的根本原因，必须写进方法学论证 | 同上 §1.1 |
| B3 | **Gateway CHARLS D.2 只覆盖 2011–2018**（wave 5 段被注释） | 决定了 8 年分析改 7 年，且 2020 波需自建 | 同上 §1.2 |
| B4 | **BMI 变量陷阱** `qh006`(43.0) vs `qi002`(157.9) | 误用会使 BMI 可得率从 76.7% 崩到 0.5% | `fi_specification` §4 |
| B5 | **ADL 跳转逻辑** (`.do` 6484 行) | 漏掉会人为抬高缺失率、压低 FI | 同上 §3.2 |
| B6 | **`shlt` 由 da001 + da080 双题合成**（选项顺序相反） | 只用其一会造成大量缺失 | 同上 §4 |
| B7 | **IC 的分母口径问题**：步速全样本 32.6% vs 60+ 74.5% | 我自己第一次判错了，是个方法学教训，值得写进 Limitations 的测量部分 | `ic_specification` §1, §3.1 |
| B8 | **IC 必须用 min-max 而非 z 分数标准化** | z 分数依赖样本，模型无法迁移。这是 IC 跨队列研究最常见的致命错误 | 同上 §4.1 |
| B9 | **开发集/验证集的时间精度不对称** | CHARLS 只能波次级，验证集多有精确日期。需在 Methods 声明 + 做敏感性分析 | `seven_cohort_timeframe` §5 |
| B10 | **KLoSA 变量命名每波不同** (`w02Xa010y`→`w09X_A010Y`) | 工程实现的坑，不能用统一正则 | 同上 §3.3 |
| B11 | **ELSA 死亡随访止于 2012** 的实测证据（iwstat 逐波表） | 排除 ELSA 的依据，审稿人可能会问"为什么不用 ELSA" | 同上 §2.1 |
