## 2. 研究概述

### 2.1 背景与研究问题

> **4年全因死亡预测模型（FI 41项，cohort-specific 阈值）的判别力、校准度与临床效用，能否在中国内部（CHARLS→CLHLS）、亚洲内部（→KLoSA）以及欧洲、美国、墨西哥队列（→SHARE / HRS / MHAS）中保持稳定；若不能，性能损失可分解为多少来自事件率差异、协变量分布漂移、测量不等价？**

### 2.2 创新点

1. 首个系统性量化老龄化预测模型跨文化迁移失败机制的研究
2. 三级验证阶梯（同国→亚洲→跨洲）消除混杂因素逐级归因
3. 降采样对照剔除多队列训练的样本量混杂
4. SHARE 内 leave-one-country-out 提供20+国独立目标证据

## 4. 纳入与排除标准

以下标准统一适用于全部6个队列：

**纳入标准**：
1. 基线波次年龄 ≥ 60 岁
2. 基线时存活并完成个人访谈
3. FI 可计算：非缺失 deficit 项目数 ≥ cohort-specific 阈值（即 80% 可得项目数）
4. 有可用随访状态信息（能判定4年内死亡或存活/失访）

**排除标准**：
1. 基线死亡或基线前死亡（CLHLS：`prebaseline_death = TRUE`，45例，见 D-019）
2. 基线年龄缺失

**各队列附加说明**：
- **CHARLS**：2011 wave 1 为基线；跨波 ID 桥接成功率 2015=85.5%、2018=81.3%，未匹配个体视为失访（D-009）
- **CLHLS**：随访天数 < 0 的4例（死亡日期矛盾）：保留死亡状态，时间变量置 NA（D-019）
- **SHARE**：仅纳入 wave-4 2011年访谈记录（`r4iwy == 2011`），排除2010和2012年访谈（D-021）
- **MHAS**：age 优先取 `r3agey`，缺失时用 `r3iwy - rabyear` 推算；无法推算者排除（D-022）

## 5. 主要结局定义

### 5.1 一级结局（Primary Outcome）

**4年全因死亡**（all-cause mortality within 4 years of baseline）

由于 CHARLS 2015/2018 波次仅有生存状态标记（无死亡日期，D-010），采用**离散时间框架**（discrete-time survival）：

| 风险期 | 时间段 | 开发集使用 |
|---|---|---|
| 期1 | 2011→2013 | ✅ |
| 期2 | 2013→2015 | ✅ |
| 期3 | 2015→2018 | 敏感性（7年结局） |
| 期4 | 2018→2020 | 探索性（约9年） |

**主要结局 = 期1 + 期2**（约4年，2011→2015）。在验证队列中，有精确死亡日期者（CLHLS、HRS、SHARE、MHAS）以 ≤1461 天（4×365.25）作为等价切点。

### 5.2 次要结局（Secondary Outcome）

**约7年全因死亡**（期1+2+3，2011→2018，仅 CHARLS + CLHLS 可比），用于时间窗稳定性敏感性分析。

## 6. 预测变量规格

### 6.1 Frailty Index（FI_full）

**来源**：D-020（冻结，2026-07-28）；变量定义从 Gateway `.do` 文件提取并用 R/Python 复刻（D-007）

**项目数**：41 deficits，涵盖7个域

| 域 | 项数 | 代表项目 |
|---|---|---|
| 共病 | 13 | hibpe, diabe, cancre, lunge, hearte, stroke, psyche, arthre, dyslipe, livere, kidneye, digeste, asthmae |
| ADL | 5+1* | dressa, batha, eata, beda, toilta, urina* |
| IADL | 5 | housewka, mealsa, shopa, moneya, medsa |
| 活动能力 | 9 | walk100a, walk1kma, joga, climsa, chaira, stoopa, armsa, lifta, dimea |
| 感官 | 3 | dsight, nsight, hearing |
| 综合健康 | 4+ | shlt, mbmi, painfr, fall, slfmem** |
| 认知 | 0*** | — |

*urina 归入 ADL（D-020）；**slfmem 为认知代理，5/6队列可得（KLoSA缺）；***cogtot 未在任何队列 parquet 中构建（D-028），论文 Methods 中须透明说明

**编码规则**：
- 二分类 deficit：0=无，1=有
- 5分量表（dsight, nsight, hearing, shlt, slfmem）：`(val-1)/4`，其中 val=6（完全丧失）→ 1.0（D-026）
- ADL：使用 `a` 版（some difficulty），不使用 `b` 版（needs help）（D-020）
- ADL 跳转规则：若同组7个前提项目全部=1（无困难），则该 ADL 项编码为0而非缺失（D-020）
- BMI：WHO 切点，< 18.5 或 ≥ 30 → deficit=1（D-015）

**FI 计算**：`FI = Σ(deficit_i) / N_valid`，其中 `N_valid` = 当前个体非缺失 deficit 数

**可计算阈值**：每个队列独立计算 `threshold = ceiling(0.8 × found_stems)`：

| 队列 | found_stems | threshold | FI_full median(60+) |
|---|---|---|---|
| CHARLS | 41 | 33 | 0.200 |
| CLHLS | 41 | 33 | 0.169 |
| KLoSA | 41 w/subs | 33 | 0.095 |
| HRS | 41 w/subs | 33 | 0.287 |
| SHARE | 41 w/subs | 33 | 0.169 |
| MHAS | 27 | **22** | 0.220 |

## 8. 统计模型

### 8.1 主分析模型

**A. 基础模型（Model A）**：`logit(P_t) = β_0 + β_age·age + β_sex·sex + β_edu·edu`  
**B. FI模型（Model B）**：`logit(P_t) = β_0 + β_FI·FI + β_age·age + β_sex·sex + β_edu·edu`

两种连接函数均作为主分析报告：
- **Pooled logistic regression**（logit 连接）
- **Complementary log-log（cloglog）**（D-010）

对于 CHARLS（开发集），使用 person-period 长表（每人每风险期1行，n=64,792行，D-010）。对于拥有精确死亡日期的验证队列（CLHLS、HRS、SHARE、MHAS），使用4年二元结局（1=≤1461天死亡，0=存活/失访）。KLoSA使用波次追踪的二元4年结局。

### 8.2 Model C（IC 增量模型，敏感性）

`logit(P_t) = Model B + IC_score`（内在能力综合评分，5域 min-max 标准化后合并）。由于 IC 构建规格尚待确定，Model C 不在本 SAP 主分析中冻结，须在独立 SAP 修订中规定。

### 8.3 回归系数估计

- 开发集（CHARLS）：最大似然估计（MLE），标准误按家庭/PSU 聚类校正
- 模型冻结：记录截距 + 全部系数 + 预测公式，冻结为标量后原样应用于验证集（不在验证集重新拟合系数）
- 置信区间：bootstrap 1000 次迭代（按家庭/PSU 分层聚类重采样）

## 9. 性能评估指标

以下指标对每一个 source-target 组合均须完整报告。

### 9.1 判别力（Discrimination）

| 指标 | 估计量 | 说明 |
|---|---|---|
| Harrell C-index | 标准 | 主要判别指标，含95% CI（bootstrap） |
| Uno C-index | Uno 2011 | 对删失更稳健，审稿人常要求 |
| 4年 time-dependent AUC | Blanche 估计量 | 特定时间点的 AUC，用4年切点 |
| ΔC（FI 增量） | Model B - Model A | 量化 FI 对年龄+性别+教育基础上的判别增量 |

### 9.2 校准（Calibration）

| 指标 | 说明 |
|---|---|
| Calibration-in-the-large（O:E） | 观测死亡数 / 预测死亡数，理想=1.0 |
| Calibration slope | 线性预测值的系数，理想=1.0；< 1 表示预测过于极端 |
| Calibration intercept | 截距项，理想=0；偏移表示整体风险高/低估 |
| Calibration plot | 按预测风险10分位分组，画观测率 vs 预测率（含 Lowess 曲线） |
| Hosmer-Lemeshow 统计量 | 辅助报告，不用作主要校准判据（样本量敏感） |

### 9.3 临床效用（Clinical Utility）

| 指标 | 参数 | 说明 |
|---|---|---|
| Decision Curve Analysis（DCA） | 阈值范围 5%–40%（预先规定） | 报告净获益，与「全部干预」「全不干预」比较 |
| 净获益（Net Benefit） | 在预先规定阈值 20% 处重点报告 | 便于跨研究比较 |

### 9.4 综合评分

| 指标 | 说明 |
|---|---|
| Integrated Brier Score（0–4年） | 预测概率的 MSE 积分 |
| IPA（Index of Prediction Accuracy） | `1 - (IBS_model / IBS_null)`，量化相对于零模型的改善 |

## 10. 验证结构（三 Aim）

### 10.1 Aim 1：中国内部可迁移性

- **开发集**：CHARLS 2011（60+，n=7,551 FI-eligible）
- **验证集**：CLHLS 2011/12（60+，n=9,207 FI-eligible，3,502事件）
- **模型冻结**：CHARLS 拟合系数直接应用于 CLHLS，不重新拟合
- **报告**：全套第9节指标

### 10.2 Aim 2：亚洲多样性是否改善迁移

3轮 Leave-One-Cohort-Out（LOCO）：

| 轮次 | 训练集 | 测试集 |
|---|---|---|
| A | CLHLS + KLoSA | CHARLS |
| B | CHARLS + KLoSA | CLHLS |
| C | CHARLS + CLHLS | KLoSA |

**降采样对照（必须）**：对每个目标队列，分别报告：
- (a) 仅CHARLS单队列模型的性能
- (b) 多队列模型的性能
- (b') 多队列模型降采样至与(a)相同样本量 + 事件数后的性能分布（200次bootstrap）

**对比方式**：(b) vs (a) 的 ΔC-index 及95% CI；(b') 的分布与(a)的点估计比较，判断性能差异是否可仅由样本量解释。

### 10.3 Aim 3：亚洲→欧美/拉美跨文化迁移

- **训练集**：亚洲池（CHARLS + CLHLS + KLoSA 合并，使用统一编码变量）
- **验证集**：HRS、SHARE、MHAS 各自独立（3对）
- **附加分析**：SHARE 内国家级 LOCO（27个国家逐个作为测试集）
- **报告**：每个 source-target 对的全套指标 + 性能归因分解（第13节）

## 12. 缺失数据处理

### 12.1 FI 缺失

FI 缺失由构建时的 cohort-specific 阈值处理（见第6.1节）。低于阈值的个体排除出分析（FI 不可计算），不做额外插补。

### 12.2 协变量缺失

使用**多重插补（MICE）**，规格如下：

| 参数 | 设定 |
|---|---|
| 插补数 m | 10 |
| 最大迭代次数 | 50 |
| 插补变量 | age, sex, edu（方法：age连续→pmm，sex二分类→logreg，edu有序→polyreg） |
| 预测矩阵 | 包含FI_full所有41个 deficit 项目 + age + sex + outcome |
| 分析 | Rubin 规则合并10次插补结果 |

**关键：开发集和每个验证集必须分别独立插补**（TRIPOD 泄漏预防要求）。不得用验证集信息训练插补模型，不得用开发集的插补模型直接应用到验证集。

### 12.3 结局缺失

失访（非死亡原因不可追踪）按**删失**处理。失访率 > 20% 的队列在论文中专节说明并讨论敏感性。已知：CHARLS 60+ 4年失访率 = 9.0%（D-010），无需专节讨论。

## 13. 迁移失败归因分解

这是本研究的核心创新。对每个 source-target 对，按以下四个层次逐步分解性能损失：

| 层次 | 诊断内容 | 方法 | 预期影响 |
|---|---|---|---|
| **L0** | 冻结模型（无重校准）基线性能 | 直接应用开发集系数 | 参考基线 |
| **L1** | 事件率漂移 | 目标队列平均死亡率 vs 开发集；重新估计截距 | 校准截距偏移 |
| **L2** | 协变量分布漂移 | 逐变量 SMD（|SMD|>0.1标注）；PSI（>0.25显著） | 预测分布变化 |
| **L3** | 测量不等价 | FI 各 deficit 阳性率对比表（60+子样本）；区分「人群更健康」vs「问法不同」 | FI量值偏差 |
| **L4** | 残差（真实效应异质性） | L0→L3 逐步重校准后剩余性能差 | 不可解释部分 |

**重校准阶梯**：
- **L0**：冻结（基准）
- **L1**：更新截距（`intercept = logit(observed_rate)`）
- **L2**：更新斜率 + 截距（目标队列最小化校准误差）
- **L3**：全量重拟合（开发集 + 目标队列联合训练）
- **L4**：增广模型（L3 + 目标队列特异性特征）

报告每个阶梯的 C-index、O:E、Calibration slope 和 IBS，绘制「重校准阶梯图」。

## 14. 预先注册假设（H1–H6）

以下假设预先冻结，检验方式在分析前固定，结果将如实报告，不因方向不支持而归入「探索性分析」。

| 编号 | 假设（零假设对立） | 检验方式 | 若被否证的含义 |
|---|---|---|---|
| **H1** | FI 在年龄+性别+教育基础上带来 ΔC ≥ 0.02 | Model B vs Model A，bootstrap CI（1000次）不含0 | FI 预测价值被年龄吸收，需审视 FI 独立性 |
| **H2** | 跨队列判别衰减相对损失 < 校准衰减相对损失 | 各 source-target 对的 ΔC_rel vs Δslope_rel，取中位比较 | 若校准更稳，说明绝对风险可迁移，是更强结论 |
| **H3** | 加入第二个亚洲队列后，目标队列性能改善，且降采样后（200次）改善仍成立 | Aim 2 LOCO：(b) vs (a)；(b') vs (a) | 多样性无效 → 迁移瓶颈在测量而非人群构成 |
| **H4** | 事件率漂移 + 协变量分布漂移解释 ≥ 50% 的 C-index 损失 | 归因分解 L1+L2 后剩余损失 / 总损失 ≤ 50% | 残差大 → 真实效应异质性，需在 Discussion 深入讨论 |
| **H5** | FI（Model B）的跨队列 C-index 一致性 > IC 五域（Model C）的一致性 | 各目标队列 C-index 的 IQR：Model B vs Model C | IC 更稳 → 推翻简单计数更稳健的直觉 |
| **H6** | SHAP 特征重要性排序跨队列 Spearman 相关 ≥ 0.7，年龄和 FI 位居前三 | 逐队列 SHAP + 跨队列排序矩阵 | 排序不稳 → 模型依赖队列特异关联，泛化性论证需收敛 |

**H5 注**：Model C（IC）规格未在本 SAP 中冻结，H5 检验在 IC SAP 修订确认后方可执行。
