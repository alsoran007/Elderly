## 2. IC 与 FI 的分工（为什么不合并）

| | FI（主预测因子） | IC（并行模块） |
|---|---|---|
| 概念方向 | 负向——数"有多少问题" | 正向——数"还剩多少能力" |
| 理论来源 | Rockwood 缺陷累积模型 | WHO 健康老龄化框架 |
| 测量依赖 | 几乎全部问卷条目 | **大量依赖体检实测** |
| 跨队列可得性 | 高（问卷题目高度相似） | **中低（体检协议差异大）** |
| 本项目定位 | **主预测因子** | 并行/敏感性模块 |

**不把 FI 和 IC 合成一个总分的三个理由：**

1. **构念方向相反。** 合成会互相抵消，得到一个无法解释的数。
2. **测量等价性风险不同。** FI 用比例计算，对项目集变化稳健；IC 各域需要跨队列同尺度，风险高得多。
3. **这正是本项目的一个科学问题（H5）。** 假设 H5 预期"FI 的迁移稳定性优于 IC"。要检验它，两者必须保持独立。

## 4. 五域的操作化定义

### 4.1 标准化策略（关键决策）

**必须用 min-max 标准化到 0–100，不能用 z 分数。**

理由：z 分数依赖**当前样本**的均值和标准差。若开发集（CHARLS）和目标集（HRS）各自算 z 分数，同一个人的 IC 会因所在队列而变，模型无法迁移。这是 IC 跨队列研究最常见的致命错误。

**本项目规则：**

```
连续变量：用理论或预先固定的 min/max 做 min-max 映射
        IC_domain = 100 × (value - min_fixed) / (max_fixed - min_fixed)

序数变量：按等级等距映射到 0–100
        如 5 分量表：1→100, 2→75, 3→50, 4→25, 5→0

固定的 min/max 一律取自 CHARLS 开发集，并写入变量字典冻结。
应用到目标队列时使用同一组参数，不重新计算。
```

**方向统一**：IC 是**正向**指标，分数越高代表能力越好。与 FI（越高越差）方向相反，编码时务必核对。

### 4.2 各域计分

| 域 | 组成 | 计分方法 |
|---|---|---|
| **Locomotion** | 握力（`gripsum`）+ 步速 + 平衡 | 三项各标准化到 0–100 后取均值 |
| **Vitality** | BMI + 峰流速 | 两项各标准化后取均值 |
| **Cognition** | 定向 + 即时回忆 + 延迟回忆 + 连续减7 + 临摹 | 五项总分标准化到 0–100 |
| **Psychology** | CES-D-10 | 反向计分后标准化到 0–100 |
| **Sensory** | 远视力 + 近视力 + 听力 | 三项等距映射后取均值 |

**IC 总分 = 五域均值（等权）**。但**必须同时报告五域各自的结果**——若某域驱动了全部信号，等权总分会掩盖这一点。

### 4.3 握力的处理（复刻 Gateway）

`.do` 文件对握力有一套优势手逻辑（`gripsum`，第 49918 行附近）：

```stata
gripsum = rgrip  if domhand == 1        // 右手为优势手
gripsum = lgrip  if domhand == 2        // 左手为优势手
gripsum = max(rgrip, lgrip) if domhand == 3 或缺失
```

其中 `rgrip` / `lgrip` 各自是两次测量的均值。**必须复刻这套逻辑**，不要简单取四次测量的均值。

### 4.4 步速的处理

`qg002` / `qg003` 是**两次测试的耗时（秒）**，中位数约 4.2 秒 / 4.0 秒。

- 取两次的**较快值**（或均值，需预先规定；建议取均值以降低测量误差）
- 转为速度：`speed = distance / time`。**必须先确认 CHARLS 的步行距离**（`.do` 或问卷中查，通常为 2.5 米）
- `.do` 第 49249 行有合理值规则：`inrange(qg002, 0, 100)` 有效，`101–900` 标为 `.i`，`993` 标为 `.x`，`999` 标为 `.r`
- 需排除使用助行器者（`qg005` = Aid Used）或加标记变量

## 6. 跨队列可比性风险评估

这一节是 IC 最大的问题所在，也是决定 IC 能否进主模型的依据。

### 6.1 各域风险分级

| 域 | 风险 | 具体问题 |
|---|---|---|
| **Sensory** | 🟢 低 | 各队列均为 5 分自评视力/听力，措辞相近 |
| **Vitality** | 🟡 中 | BMI 各队列都有；但**峰流速多数队列缺失**，需替代或降域 |
| **Cognition** | 🟠 中高 | 各队列都测词语回忆，但**词表长度、语言、难度不同**；中文与英文的回忆难度不等价 |
| **Psychology** | 🔴 高 | **量表完全不同**：CHARLS/KLoSA 用 CES-D-10、HRS/ELSA 用 CES-D-8、SHARE 用 EURO-D、MHAS 用 CES-D-9 |
| **Locomotion** | 🔴 **最高** | 体能测试**协议不同**（距离、计时、助行器规则），且**覆盖率差异大** |

### 6.2 心理域的具体不可比性

| 队列 | 量表 | 题目数 | 计分 | 界值 |
|---|---|---|---|---|
| CHARLS | CES-D-10 | 10 | 0–30 | ≥10 或 ≥12 |
| KLoSA | CES-D-10 | 10 | 0–10 | ≥4 |
| HRS | CES-D-8 | 8 | 0–8 | ≥3 或 ≥4 |
| ELSA | CES-D-8 | 8 | 0–8 | ≥3 |
| SHARE | **EURO-D** | 12 | 0–12 | ≥4 |
| MHAS | CES-D-9 | 9 | 0–9 | ≥5 |
| CLHLS | 自编情绪题 | 7–8 | 各题 1–5 | 无统一界值 |

**CES-D-10 的 8 分和 EURO-D 的 8 分含义完全不同。** 直接把"抑郁得分"当同一变量放进模型是错的。

**两种解法：**

- **方案 A（连续，风险高）**：各量表分数标准化到 0–100 后当同一变量。**要求通过 scalar invariance 检验**，否则不可用。
- **方案 B（二分类，稳健）**：用各量表自己已验证的界值转成"抑郁症状阳性 = 1"。牺牲信息量，换取可比性。**这是 FI 规格采用的做法**（抑郁作为一个 deficit）。

**建议**：IC 心理域优先尝试方案 A 并做检验；若检验不通过，退回方案 B，并明确报告这一降级。

### 6.3 运动域的协议差异

各队列步速测试的距离与规则不同（需逐队列查文档确认）。常见差异：

- 步行距离：2.5m / 4m / 8ft / 6m
- 是否允许助行器
- 计时起止规则（静止起步 vs 行进中计时）
- 是否取两次的较快值或均值

**这些差异使"步速（m/s）"在跨队列间不可直接比较**，即使单位相同。

## 7. 测量等价性检验（IC 定位的决定性步骤）

**在 IC 进入任何主模型之前，必须完成本节检验。**

### 7.1 检验方法

对**认知域**和**心理域**（题目级数据可得的两个域）做多组验证性因素分析（CFA）的不变性检验：

| 层级 | 约束 | 通过意味着 |
|---|---|---|
| **Configural** | 因子结构相同 | 各队列测的是同一个构念 |
| **Metric（弱）** | 因子负荷相等 | 单位可比，**可比较关联强度** |
| **Scalar（强）** | 截距也相等 | **可比较均值和绝对分数** |

判定标准（常规惯例）：ΔCFI < 0.01 且 ΔRMSEA < 0.015 视为通过。

**补充**：对认知题目做 **IRT 的 DIF 检验**（差异项目功能），识别哪些具体题目在跨队列时表现不同。中文词表与英文词表的回忆难度差异应会在这里显现。

### 7.2 三种结果对应三种定位

| 检验结果 | IC 的定位 |
|---|---|
| Scalar invariance 成立 | ✅ IC 总分可作主模型变量（Model C/D 升为主要分析） |
| 仅 Metric 成立 | 🟡 IC 只能用于**域别**增量预测，不可比较绝对分数 |
| 连 Configural 都不成立 | 🔴 IC 降级为**单队列内**的敏感性分析，不做跨队列迁移 |

### 7.3 我的诚实预判

**Scalar invariance 很可能不成立**，理由：

1. 心理域用了 4 种不同量表（CES-D-8/9/10、EURO-D）
2. 认知域的词表跨语言难度不等价（C12 的 10/66 研究已在多国队列中观察到 IC 潜在结构差异）
3. 运动域协议不同，且题目级数据往往不可得（很多队列只发布派生的汇总分）

**因此本规格的建议定位是**：IC 作为**并行模块 + 敏感性分析**，而非第一篇论文的主预测因子。

**这个谨慎态度本身是论文的方法学贡献。** C11、C12 都呼吁"跨国 pooled 分析前应做潜在结构检验"，但目前尚无预测模型研究真正照做。我们做了，无论结果如何都值得报告——**"IC 未通过跨队列等价性检验"是一个有价值的阴性发现**，能解释为什么已有 IC 研究的跨国结论应谨慎解读。

问题 2 建议现在就定，因为它直接影响第一篇的范围与工作量。

**我推荐"IC 不进第一篇主模型"的四个理由：**

1. **风险隔离。** IC 的跨队列等价性大概率不成立（4 种抑郁量表、跨语言认知词表、体能测试协议差异）。若把 IC 绑进主模型，一旦等价性检验失败，整篇论文的主结论都受牵连。而 FI 用比例计算，对项目集变化稳健，风险低得多。
2. **工作量。** IC 五域 × 7 队列的协议核实 + CFA/DIF 检验，保守估计 3–4 周。第一篇的关键路径已经很长。
3. **IC 本身值得一篇独立论文。** "WHO 的 IC 框架在跨国队列中是否具备测量等价性"是一个完整的研究问题，文献中尚无预测模型研究认真回答。塞进第一篇的一个小节反而浪费。
4. **审稿策略。** 第一篇讲清"FI 的跨文化可迁移性 + 性能损失归因分解"已经足够充实。加入 IC 会分散主线，审稿人容易质疑"你到底想证明什么"。

第一篇仍然报告 Model C/D，但明确标注为敏感性分析，并在 Discussion 中点出"IC 的跨队列等价性有待专门研究"，为第二篇埋伏笔。
