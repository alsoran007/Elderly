### 3.2 FI 分布与数据完整性

FI 构建采用冻结的 41-item 规范，并对有序健康项目统一进行 [0,1] 标准化。CHARLS、CLHLS、KLoSA、HRS 和 SHARE 均达到 41/41 stems；MHAS 为 27/41 个队列特异可获得条目，并使用预先规定的可计算阈值。FI 分布显示明显的队列异质性：KLoSA 的中位 FI 为 0.095，而 HRS 为 0.287；SHARE 与 CLHLS 均为 0.169。该差异说明 FI 的跨队列比较不能只依赖同一数值阈值，还需结合人群构成、条目可获得性和结局率解释。

CLHLS 是结局缺失最需要关注的队列。9,207 名 FI-eligible 参与者中，7,095 人具有可观测的四年结局，2,112 人的 `event_4y` 为缺失，包括基线前死亡或失访/死亡日期无法构造者。完整案例分析没有将未知结局编码为存活；IPCW 敏感性分析用于评估这一处理对性能估计的影响。教育变量在六个队列中均可获取（ID 关联率 100%，缺失率 0.00%–0.53%），但为维持预注册模型规格的完整性，未纳入主模型；其影响见事后敏感性分析 SA-3（§3.10）。

### 3.3 CHARLS 开发集模型

在 CHARLS 2011 年开发集中，period 1–2 的 FI-eligible person-period 数据包含 7,546 名参与者、14,551 条完整 person-period 记录和 771 个事件。Model A 包含年龄、性别和 period 指示变量；Model B 在此基础上加入 FI。系数估计见表 2。

Model A 的表观 C-index 为 0.7355，加入 FI 后 Model B 的表观 C-index 提高至 **0.7705**，增量 ΔC 为 **0.0351**。以个体为重抽样单位进行 200 次内部 bootstrap 后，平均 optimism 为 0.0004（SD=0.0085），optimism-corrected C-index 为 **0.7701**，表明过拟合程度很小。因此，预先设定的 H1（FI 在年龄和性别基础上提供至少 0.02 的判别增量）**成立**。

### 3.4 Aim 1：CHARLS 至 CLHLS 的外部验证

将 CHARLS Model B 系数冻结后，按离散时间风险公式计算 CLHLS 四年累计死亡风险。CLHLS 完整案例中观察到 3,282 个死亡事件，事件率为 **46.3%**。模型的 C-index 为 **0.8389**（500 次 bootstrap 95% CI：0.8301–0.8481），显示判别力保持良好。O:E ratio 为 **1.2473**，校准截距为 0.5976，校准斜率为 0.9393，提示模型在 CLHLS 中总体低估了死亡风险，但预测排序和风险梯度仍较稳定。Brier score 为 0.17509，IPA 为 0.2957，DCA 已完成。

### 3.6 Aim 3：亚洲池至 HRS、SHARE 和 MHAS 的外部验证

CHARLS、CLHLS 和 KLoSA 合并形成亚洲训练池，共 19,934 人、4,563 个事件，事件率为 22.9%。在 HRS 中，L0 模型 C-index 为 0.7901、O:E 为 0.8205、校准斜率为 0.9671、IPA 为 0.1927；经过 L3 后 C-index 为 0.7929、O:E 和斜率均为 1.000、IPA 为 0.2111。SHARE 的 L0 C-index 为 0.7780、O:E 为 0.599、斜率为 0.8381、IPA 为 0.0276；L3 后 C-index 为 0.7797、IPA 为 0.1194。MHAS 的 L0 C-index 为 0.7243、O:E 为 0.6769、斜率为 0.6859、IPA 为 −0.0022；L3 后 C-index 为 0.7245、斜率为 1.000、IPA 为 0.0817。

判别力从 L0 到 L3 的变化很小，而截距和斜率更新明显改善校准。由此，H2（跨队列判别衰减小于校准衰减）**成立**。H4（事件率和协变量分布漂移解释至少 50% 的性能损失）也**成立**：单独 L1 事件率校正解释了 HRS 可改善空间的 **87.5%**、SHARE 的 **93.9%** 和 MHAS 的 **78.2%**（均以 L0→L3 完整跨度为分母），三队列全部超过 50% 门槛。MHAS 的 L0 IPA 为 −0.0022，提示其事件率较亚洲池更低；L1 后 IPA 为 0.0634，L2 后进一步升至 0.0816，说明 MHAS 需要斜率重校准才能获得较可靠的绝对风险估计。

SHARE 的 19 个国家/地区内部 C-index 范围为 0.6911–0.8564，中位数约为 0.768。最低值见荷兰，最高值见法国（Cf），提示即使在同一调查框架内，国家层面的事件率和人群构成差异仍会影响判别表现。

### 3.7 CLHLS 缺失结局的 IPCW 敏感性分析

CLHLS FI-eligible 人群中，22.9% 的四年结局缺失，缺失观察与 FI 和年龄相关，提示删失并非完全随机。IPCW 加权后 C-index 为 0.8397，相比完整案例分析的 0.8389，ΔC 仅为 **+0.0008**；O:E 从 1.2473 变为 1.2547，校准斜率从 0.9393 变为 0.9458，Brier score 从 0.17509 降至 0.17399，IPA 从 0.2957 升至 0.2967。所有变化均较小，说明 Aim 1 完整案例结果对信息性删失具有稳健性。

### 3.8 H6：跨队列特征重要性一致性

基于 FI_core 19 个条目加年龄的队列特异 logistic 模型，六个队列中年龄均为第一重要特征。其余高排名特征具有队列差异：自评健康（`shlt`）在 CHARLS、HRS、SHARE 和 MHAS 中进入前 3 位，`mealsa` 在 CLHLS 和 KLoSA 中排名靠前。六队列特征重要性排序的 Spearman 相关中位数为 **0.4105**，范围为 0.0962–0.6677；最低相关为 KLoSA–HRS（0.0962），最高为 CHARLS–SHARE（0.6677）。因此，H6 **部分成立**：年龄在 6/6 个队列中排名第一，但预设的中位 Spearman ≥0.70 未达到，提示具体 deficit 的预测重要性存在跨队列异质性。

### 3.9 补充分析：FI 与内在能力（IC）的跨队列稳定性

作为 H5 的补充分析（IC 按 D-012 不进入主模型，本节为敏感性/补充分析），比较 CHARLS 开发集至 CLHLS 外部验证中 FI 与 WHO 内在能力五域框架的 C-index 变化。FI Model B 的 CHARLS 内部 C-index 为 0.7608，CLHLS 外部 C-index 为 0.8131，绝对变化为 **0.0523**；IC Model C 的对应 C-index 为 0.7105 和 0.8060，绝对变化为 **0.0955**。FI+IC 的 Model D 变化为 0.0906。FI 的跨队列变化幅度小于 IC，因此 H5 **成立**。

该结论需要谨慎解释：由于 CLHLS 原始 IC 测量不可完整获得，Model C/D 使用 FI 条目的二元代理，而非连续的握力、步速、峰流量和认知测量；CLHLS 有效 IC 代理样本为 5,678 人，且外部 C-index 的 bootstrap 区间未能收敛，当前仅报告点估计。完整的连续 IC 外部验证将作为后续 Paper 2 的研究内容。

### 3.10 敏感性分析：限定为跨队列共同条目（SA-1）

由于各队列可得 FI 条目数不同（CHARLS、CLHLS、KLoSA、HRS、SHARE 为 41/41，含已记录的替代变量；MHAS 为 27/41），我们使用 **FI_core**——六队列在严格列名匹配下共同可得的 19 个 deficit（D-028）——重复分析，统一可计算阈值为 19 项中至少 16 项。此分析直接检验结论是否依赖于条目可得性，而非衰弱负担本身。

**四个跨队列 ΔC 全部低于 0.02 阈值**（范围 −0.0124 至 −0.0000），说明将指数限定为各队列共同可得条目并未实质削弱判别力。两点观察进一步支持这一判断。第一，统一的 16/19 阈值使 HRS 分析样本减少 27%（10,707 → 7,823），但 C-index 仅下降 0.0124——损失来自样本限制而非预测信息丢失。第二，MHAS 的 ΔC 几乎为零，这符合预期：其 FI_full 本就仅基于 27 项，故该队列的 FI_full 与 FI_core 信息基础高度重叠。

### 3.11 事后敏感性分析：教育调整（SA-3）

2026-07-30 的事后可得性排查证明教育变量在六个队列中均可获取（详见 `results/education_availability_audit.md`），否定了先前记录中「教育无法可靠关联」的结论。由于 SAP v1.0 已冻结且结局已揭盲，教育未追加入主模型；SAP 修订 A-001 在执行分析前冻结了 ISCED 映射规则，并声明 SA-3 为事后敏感性分析（Methods §8.5）。

教育是独立的死亡预测因子，方向符合预期（`edu_isced` β = −0.4475，p = 0.0031；教育程度越高，死亡风险越低）。将其加入模型后，性能几乎不变（表 5）：CHARLS 内部 C-index 从 0.7706 升至 0.7725（ΔC = +0.0020，教育完整样本：7,534 人，770 个事件，12 人因教育缺失被排除）；CLHLS 外部 C-index 从 0.8389 降至 0.8380（ΔC = −0.0009），O:E 从 1.2469 降至 1.2402，校准斜率从 0.9379 降至 0.9315，IPA 不变（26 人因教育缺失被排除）。三条预设稳健性判据（|ΔC| < 0.02、|ΔO:E| < 0.05、|Δ斜率| < 0.05）全部满足。

### 3.12 预注册假设判定汇总

H1 **成立**（CHARLS 中 ΔC=0.0351，optimism-corrected C-index=0.7701）；H2 **成立**（跨队列判别力变化小于校准变化）；H3 **不成立**（降采样 LOCO 的 ΔC 为 +0.0013 和 −0.0013）；H4 **成立**（事件率校正解释三队列 78.2%–93.9% 的可改善空间）；H5 **成立**（FI 跨队列 |ΔC|=0.0523 小于 IC |ΔC|=0.0955，但 CLHLS IC 使用二元 FI 代理，结论具有探索性）；H6 **部分成立**（年龄排序完全稳定，但中位 Spearman=0.4105，低于 0.70 阈值）。
