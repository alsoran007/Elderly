## 1. 研究设计（Study Design）

本研究为多国纵向老龄化队列的预测模型开发与外部验证研究，遵循预测模型报告规范 TRIPOD+AI[CITATION] 和 PROBAST-AI 偏倚风险评估框架[CITATION]。研究包含三个验证目标（Aim）：（1）中国内部可迁移性（CHARLS→CLHLS），（2）亚洲多队列 leave-one-cohort-out 分析，（3）亚洲池→欧美/拉美跨文化验证。所有分析方案在启动任何结局关联分析前在统计分析计划（SAP）中预先注册。

## 3. 研究对象（Participants）

**统一纳入标准**：（1）基线时年龄≥60岁；（2）基线时存活并完成个人访谈；（3）衰弱指数（FI）可计算（见第5节）。

**各队列附加说明**：
- *CHARLS*：基线为2011年wave 1；由于2011年（11位）与后续波次（12位）个体ID格式不同，使用官方Gateway do文件（`bbxleyec.do`）验证的ID桥接规则进行跨波匹配（规则：`pid_12 = householdID_11 + "0" + id_11[-2:]`；2015年匹配率85.5%，2018年81.3%）。
- *CLHLS*：排除45例基线前死亡（随访天数<0），其事件变量设为缺失（not-at-risk）。
- *SHARE*：仅纳入wave-4 2011年访谈记录（占全wave-4的94.1%），以确保基线时间一致性。
- *MHAS*：年龄优先使用直接测量值（`r3agey`），缺失时用 访谈年份 − 出生年份推算。
- *KLoSA*：使用wave 4（2012年）作为基线，只纳入与wave 4基线匹配的个体。

**排除标准**：基线年龄缺失；FI不可计算（非缺失 deficit 项目数低于队列特定阈值）。

## 4. 主要结局（Primary Outcome）

**主要结局**：4年全因死亡（all-cause mortality within 4 years of baseline）。

由于 CHARLS 2015年及2018年波次仅记录受访者存活状态（`died_by_wave`），无精确死亡日期，我们采用**离散时间生存框架**（discrete-time survival framework）：

- 风险期1（Period 1）：基线→2013年退出访谈（约2年）
- 风险期2（Period 2）：2013→2015年访谈（约2年）

主要结局 = 期1或期2内死亡（二元变量，即**2011→2015年内死亡**），对应约4年随访窗口。

对于拥有精确死亡日期的验证队列（CLHLS、HRS、SHARE、MHAS），以基线后 **≤1461天**（4×365.25天）作为等价4年切点，构建二元结局变量（1=死亡，0=存活/失访）。KLoSA 使用波次追踪的生存状态确定4年结局。

**敏感性结局**：约7年全因死亡（期1+2+3，2011→2018；仅CHARLS+CLHLS可比），用于时间窗稳健性分析。

## 5. 衰弱指数构建（Frailty Index Construction）

**FI 定义**：采用 Rockwood 缺陷累积模型。FI = Σ(有效缺陷得分) / 非缺失缺陷项目数，理论范围 [0,1]。所有队列的 FI 变量定义均从 GATEWAY 协调化数据库官方 `.do` 脚本（H_CHARLS_long D.2；H_KLoSA_long F）中提取，并用 Python/R 重新实现（无需 Stata）。

**41项最终清单**（D-020，2026-07-28冻结）涵盖7个域：

| 域 | 项数 | 代表项目 |
|---|---|---|
| 共病 | 13 | 高血压、糖尿病、癌症、肺部疾病、心脏病、脑卒中、精神疾病、关节炎、血脂异常、肝脏疾病、肾脏疾病、消化疾病、哮喘 |
| 日常生活活动（ADL） | 5+1† | 穿衣、洗澡、进食、床椅转移、如厕、尿失禁† |
| 工具性日常生活活动（IADL） | 5 | 家务、做饭、购物、理财、药物管理 |
| 活动能力 | 9 | 步行100米、步行1公里、慢跑/体力活动、爬楼、从椅子起立、弯腰、举臂、搬重物、辨别硬币 |
| 感官 | 3 | 近视力、远视力、听力 |
| 综合健康 | 4 | 自评健康、BMI异常、慢性疼痛、跌倒、记忆自评‡ |
| 认知代理 | — | 记忆自评（归入综合健康，cogtot 未在任何队列 parquet 中构建）|

†尿失禁在本研究中归入 ADL 第6项  
‡slfmem（记忆自评）作为认知域代理，5/6队列可得（KLoSA 缺失）

**关键编码规则**：
- 所有缺陷二分类编码（0=无，1=有）；5分量表变量（视力、听力、自评健康、记忆自评）采用 `(原始值−1)/4` 映射到 [0,1]（D-026）
- ADL 使用"有些困难"（some difficulty）版本
- ADL 跳转逻辑：若同组前提项目全部为0（无困难），则该 ADL 项编码为0，而非缺失
- BMI 使用 WHO 切点（< 18.5 或 ≥ 30 kg/m²）
- **可计算阈值**：每个队列独立计算，threshold = ⌈0.8 × 当前队列可得 stems 数⌉（MHAS 仅有27/41 stems，threshold = 22）

## 6. 协变量（Covariates）

所有模型均包含以下基线协变量：年龄（连续型，岁）、性别（0=女，1=男）。教育变量在六个队列中均可获取（ID 关联率 100%，缺失率 0.00%–0.53%；见事后可得性排查 `results/education_availability_audit.md`，2026-07-30），但**未纳入主模型**，以维持预注册模型规格（SAP v1.0，commit 9bc7b85）的完整性。跨队列可比性需将三个队列的调查特异编码（CHARLS 11 级、CLHLS 受教育年数、KLoSA 4 级）映射到 HRS/SHARE/MHAS 所用的 Gateway 协调化 ISCED 三分类；该映射在结局揭盲之后确定，属事后决定。教育调整的影响见事后敏感性分析 SA-3（第 8.5 节）。

在 Aim 2 及 Aim 3 的多队列分析中，由于 KLoSA FI parquet 中性别变量未经协调，为保证跨队列模型规格一致性，统一使用 `fi_full + age`（不含性别）。Aim 1（CHARLS→CLHLS）保留性别协变量（`fi_full + age + sex`）。

---

## 7. 缺失数据（Missing Data）

**FI 缺失**：通过队列特定80%阈值内部处理——非缺失项目数低于阈值的个体直接排除（不进行外部插补），不作为缺失数据处理。

**结局缺失**：失访按删失处理，不编码为存活。CLHLS 中22.9%的FI可计算个体（2,072例）结局未知（随访丢失或死亡日期无法构建）；逆概率删失加权（IPCW）灵敏度分析证实完整案例分析稳健（加权 C-index 变化ΔC = +0.0008，见灵敏度分析）。

**协变量缺失**：主分析中仅纳入年龄和性别，两者在所有队列均接近完整（缺失<0.5%）。

## 8. 统计分析（Statistical Analysis）

### 8.1 开发集模型拟合（Model Development on CHARLS）

以 CHARLS 2011年为开发集。使用**人-时期（person-period）长表**格式，每人每风险期贡献一行（期1+2共14,551行，7,551人）。拟合以下两个广义线性模型：

- **模型A（基础模型）**：`logit(P_t) = β₀ + β_age·age + β_sex·sex + γ_t`
- **模型B（FI模型，主分析）**：`logit(P_t) = β₀ + β_FI·FI + β_age·age + β_sex·sex + γ_t`

其中 γ_t 为期次效应（period dummy）。互补对数-对数模型（complementary log-log, cloglog）作为并行分析。

**4年累积概率预测公式**（用于外部验证队列）：
$$P(\text{4年死亡}) = 1 - (1-h_1)(1-h_2)$$
其中 $h_t = \text{logistic}(\hat{\beta}'X + \hat{\gamma}_t)$，$\hat{\beta}$ 为 CHARLS 冻结系数，直接应用于验证队列（不在验证集重新拟合）。

### 8.2 三Aim验证结构

**Aim 1：中国内部可迁移性**
冻结 CHARLS 模型B系数，直接应用于 CLHLS，计算完整性能指标集。

**Aim 2：亚洲多样性与LOCO分析**
三轮 Leave-One-Cohort-Out（LOCO）：
- Round A：CLHLS + KLoSA 训练 → CHARLS 测试
- Round B：CHARLS + KLoSA 训练 → CLHLS 测试
- Round C：CHARLS + CLHLS 训练 → KLoSA 测试

每轮均进行**降采样对照**（H3假设检验）：对多队列训练集降采样至与CHARLS单队列相同的样本量，重复200次bootstrap，比较性能分布与单队列基线的差异，以排除样本量混杂。

所有LOCO模型使用统一规格：`event ~ fi_full + age`（二元逻辑回归）。

**Aim 3：亚洲池→欧美/拉美外部验证**
将CHARLS、CLHLS、KLoSA合并为亚洲训练池（N=19,934人，4,563事件，事件率22.9%），冻结系数后应用于 HRS、SHARE、MHAS（各自独立验证）。附加分析：SHARE内19个国家逐国C-index（判别力地理稳定性）。

### 8.3 模型性能评估指标

| 维度 | 指标 | 说明 |
|---|---|---|
| 判别力 | Harrell C-index | 主要判别指标，95% CI（bootstrap 300次） |
| 判别力 | FI增量判别力（ΔC） | 模型B − 模型A |
| 校准 | 观测/预测比（O:E） | 理想值=1.0 |
| 校准 | 校准截距 | 理想值=0 |
| 校准 | 校准斜率 | 理想值=1.0 |
| 综合 | Brier Score | 预测概率均方误差 |
| 综合 | IPA（预测准确性指数） | 1 − Brier/Brier_null |

### 8.4 重校准阶梯（L0–L3 Recalibration Ladder）

对 Aim 3 中每个 source-target 组合，按以下四个层次逐步重校准并报告性能：

- **L0**：冻结模型（无任何调整）——基准
- **L1**：截距更新（`logit(p_new) = logit(p_frozen) + α`，α 通过最大化对数似然估计）——纠正事件率漂移
- **L2**：斜率+截距更新（在目标队列中重拟合 `event ~ offset(s·lp)` 的两参数校准）
- **L3**：完全重拟合（在目标队列中重拟合 `event ~ fi_full + age`）——判别力天花板

该阶梯图框架用于量化性能改善来源，为实际应用中选择重校准策略提供依据。

### 8.5 灵敏度分析

| 编号 | 分析 | 规格 |
|---|---|---|
| SA-1 | FI_core（19项） | 全6队列共同可得项目，统一阈值 ceiling(0.8×19)=16 |
| SA-2 | IPCW（CLHLS） | 对 CLHLS 2,072例未知结局进行逆概率删失加权；删失模型：`P(observed | fi_full, age, sex)`；截断99th百分位权重 |
| SA-3† | 教育调整（仅 Aim 1） | 主模型 + `edu_isced`（ISCED 三分类有序整数）；完整案例 |

†**SA-3 为事后（post hoc）分析。** 由 SAP 修订 A-001（2026-07-30）新增，时点在结局揭盲之后，起因是一次可得性排查证伪了先前「教育无法可靠关联」的记录。SA-1 与 SA-2 为 SAP v1.0 预先规定。SA-3 所用的教育映射在 A-001 中于分析执行前冻结：CHARLS `bd001` 1–5→1、6–7→2、8–11→3；CLHLS `f1`（年数）0–9→1、10–12→2、≥13→3（88/99 为缺失）；HRS、SHARE、MHAS 直接使用 Gateway `raeducl`。SA-3 限定于 Aim 1，因 Aim 2/3 规格不含性别（KLoSA 缺已协调的性别变量），在该规格上追加教育会形成与主分析不可比的协变量结构。

### 8.6 特征重要性（H6：SHAP分析）

为评估 FI 各组成成分预测价值的跨队列一致性，对每个队列独立拟合逻辑回归（FI_core 19项 + 年龄 × 队列特异性系数），以标准化系数绝对值 |β_standardised| 作为线性 SHAP 重要性（该方法对主效应广义线性模型精确成立），计算跨队列秩 Spearman 相关矩阵。H6 预设判据：中位 Spearman ≥ 0.70 且年龄在每个队列中位居前3。
