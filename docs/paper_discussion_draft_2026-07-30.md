# 4. 讨论（Discussion）— 论文草稿

**文件说明**：本文件为 Discussion 节初稿，基于 SAP v1.0（commit 9bc7b85）、decision_log D-001–D-034 及全部分析结果撰写。中文初稿，后续翻译为英文投稿版本。H1–H6 判定与 SAP 冻结判定完全一致，不作任何事后调整。

---

## 4.1 主要发现

本研究在六个跨文化老龄化纵向队列（中国、韩国、美国、欧洲 27 国、墨西哥）中系统评估了基于缺陷累积模型的衰弱指数（Frailty Index，FI）预测四年全因死亡的可迁移性，是迄今规模最大的跨文化 FI 死亡预测研究之一（六队列 60 岁以上完整案例参与者 76,074 人，四年死亡事件 10,790 例）。核心发现呈现出清晰的两层结构：FI 预测模型的判别力（C-index 0.72–0.84）在跨文化迁移中保持稳健，无需重训练即可维持有临床意义的预测排序；而校准（预测事件率的绝对准确性）则呈现系统性漂移，其主要驱动因素是开发队列与目标队列间的基准死亡率差异，且可通过截距重校准加以修正。六项预先注册假设中，H1、H2、H4 和 H5 均得到支持，H3 不成立，H6 部分成立，全部结果均基于 SAP 冻结（commit 9bc7b85）后的分析，分析期间严格保持结局盲。

## 4.2 FI 在人口学协变量基础上的独立预测增量（H1）

在 CHARLS 2011 年开发集中，加入 FI 后 C-index 从 0.7355（仅年龄、性别和随访期）提升至 0.7705，净增量 ΔC = 0.035（p<0.001），满足预先设定的 H1 阈值（ΔC ≥ 0.02）。这一增量幅度与既往在英国、加拿大等西方队列中的报告一致 [CITATION]，并将该发现明确延伸至中国农村老年人群，表明 FI 超越基本人口学信息的独立预测价值具有跨文化普遍性。

FI 能够在年龄基础上提供独立预测增量，反映了其作为"综合生物年龄"指标的信息内核：年龄捕捉的是时间驱动的生物老化平均轨迹，而 FI 累积了跨越共病、功能、营养和认知等多系统的实际健康缺陷，编码了与日历年龄相独立的个体间健康异质性。这种"多系统综合性"使 FI 在不同文化情境和医疗体系下均能保持概念可比性，而依赖单一测试协议的指标（如握力切点、步速标准）则往往因测量差异而难以直接跨队列比较。

## 4.3 判别力与校准的分离：迁移性的两个独立维度（H2、H4）

本研究最具方法学意义的发现是"判别稳定、校准漂移"模式。在亚洲池→全球验证框架（Aim 3）中，L0 至 L3 的完整校准阶梯仅使 C-index 提升 0.000–0.003（HRS +0.003，SHARE +0.002，MHAS +0.000），而 O:E 比值则从系统性偏差（HRS 0.821、SHARE 0.599、MHAS 0.677）全部修正至 1.000（H2 成立）。此模式在 Aim 1（CHARLS→CLHLS：C = 0.839，O:E = 1.247）和 Aim 2（三轮 LOCO：C = 0.759–0.835，L1 后 O:E 均为 1.000）中同样一致出现，说明这一"判别-校准分离"是 FI 跨文化迁移的结构性特征，而非个别队列的偶然现象。

判别力稳健的机制与 FI 的相对排序属性直接相关。C-index 衡量的是模型对个体死亡风险的相对排序准确性，而非绝对概率的高低。FI 作为累积缺陷比例，其相对排序在本质上反映的是个体在同年龄段人群中的健康状态离散程度——高缺陷负担个体在中国、美国或墨西哥均倾向于具有相对更高的死亡风险。这种相对关系对各国绝对死亡率差异不敏感，因而判别力在跨文化迁移中得以保存。相比之下，校准要求预测绝对概率与目标队列的实际死亡率严格一致，这天然依赖开发集的基准事件率，当目标队列事件率显著偏离时（CLHLS 46.3% vs. CHARLS 10.2%；SHARE 8.7% vs. 亚洲池 22.9%）必然产生系统性偏差。

H4 进一步量化了校准失败的可归因来源。单纯 L1 截距更新——仅基于目标队列事件率的截距调整，无需重新采集预测因子数据或重训练模型——解释了 **HRS 可改善校准空间的 87.5%**（IPA: 0.193→0.209）、**SHARE 的 93.9%**（IPA: 0.028→0.114）和 **MHAS 的 78.2%**（IPA: −0.002→0.063），全部以 L0→L3 完整可改善跨度为分母。这意味着，对本研究考察的全部三个目标队列而言，一次轻量级重校准即可将跨文化模型的校准性能提升至实质性水平，操作门槛极低。

MHAS 呈现了一种重要的例外情形。亚洲池对 MHAS 的 L0 IPA 为 −0.002，意味着模型 Brier 分数劣于零预测模型——原因在于亚洲训练集的高平均事件率（22.9%，由 CLHLS 46.3% 主导）驱使模型系统性过度预测低事件率目标队列（MHAS 10.2%）。L1 调整后 IPA 升至 0.063，但斜率仍为 0.686（远低于 1.0），提示 MHAS 还需要 L2 斜率校准才能达到合理校准水平。这一结果说明，当训练集事件率构成高度不均衡时，合并训练可能同时引入斜率漂移，需要更高层次的校准干预；在此情形下，仅做 L1 调整不足以解决问题。

## 4.4 多队列训练未改善跨队列迁移性（H3，阴性结果及其含义）

H3 的不成立是本研究最具理论挑战性的阴性发现。直觉上，将训练数据从单一中国队列（CHARLS）扩展至多个亚洲队列似乎应提升模型对新人群的适应性。然而，降采样 bootstrap 分析（200 次重复，降至 CHARLS 规模以排除样本量效应）显示，加入第二个亚洲队列后 C-index 变化仅为 ±0.0013，远低于 0.02 的临床意义阈值，且方向不稳定（Round B +0.0013，Round C −0.0013）。

这一结果揭示了跨队列预测建模的一个根本性认知局限：训练集多样性能改善的是模型对训练分布的泛化能力，但当目标队列与训练集存在测量不等价（measurement non-equivalence）时，增加训练队列无法弥补这种结构性差异。FI 的 41 个缺陷项目在不同队列中由不同量表、不同截点、不同语言情境的问卷操作化，同一 "deficit" 标签在各队列中编码的可能是略有差异的健康概念。H4 的发现则进一步说明，目标队列的事件率漂移是校准失败的主因，这是目标人群的内在特性，无法通过选择训练集来规避。

H3 的阴性结果对多中心老龄化研究的资源分配具有直接启示：在推广 FI 预测模型至新人群时，与其花费大量资源将更多队列纳入联合训练，不如优先在目标人群采集少量数据用于 L1 重校准——后者仅需估计目标人群的基准事件率（四年死亡率），实施成本极低，但校准改善效果显著（SHARE: IPA 从 0.028 升至 0.114）。这一策略调整的实践价值值得在未来多国合作研究框架中认真考量。

## 4.5 特征重要性的跨队列异质性（H6，探索性分析）

基于 FI_core（19 个跨队列严格共同可得条目）和年龄的队列特异 logistic 模型显示，年龄在 6 个队列中均位居特征重要性第一（H6 条件一：成立），自评健康（`shlt`）是出现频率最高的 FI 条目（出现在 CHARLS、HRS、SHARE 和 MHAS 的前 3 位）。然而，FI_core 各条目重要性排序在队列间呈现显著异质性：六队列 Spearman 秩相关中位数为 0.41（范围 0.10–0.67），未达到 H6 预设阈值 0.70（H6 条件二：不成立）。综合而言，H6 部分成立。

年龄的一致主导性在生物学上是预期的：死亡率对年龄的依赖在几乎所有人类社会中均为最强且最稳健的预测关系。更具科学价值的是特定 FI 条目重要性的跨队列异质性。韩国（KLoSA）与其他队列的 Spearman 相关尤为偏低（与 CHARLS 0.099，与 HRS 0.096），可归因于 KLoSA 60+ 样本的人口学特性：该队列社区居住参与者多数年龄较轻（中位约 71 岁），**ADL** 缺陷阳性率仅 2–7%（穿衣、如厕等项目阳性率接近地板效应），导致 ADL 条目在统计建模中的相对权重下降；而 IADL 中的做饭困难（`mealsa`，KLoSA 排名第 2）和共病癌症（`cancre`，排名第 3）的相对重要性升高。这一模式与 CLHLS 类似（`mealsa` 同样排名第 2），提示在功能障碍率普遍较低的相对健康队列中，饮食准备能力对死亡的预测贡献更为突出。这种由缺陷分布差异驱动的特征权重异质性，从预测建模角度再次印证了H3 解释框架：测量环境差异是跨队列迁移的结构性障碍，而非单纯的训练数据问题。

需要说明分析范围的局限：本文使用标准化系数绝对值（|β_standardised|）作为特征重要性代理，与主模型的线性 logistic 框架保持一致。这一指标对变量的非线性贡献和交互效应不敏感，结果应视为探索性分析而非定型结论。基于非线性模型（如 XGBoost）的 SHAP 分析可能揭示更细腻的贡献模式，是未来研究的延伸方向。

## 4.6 FI 与 IC 的跨队列稳定性比较（H5，补充分析）

作为事先规定的补充性分析，本研究在 CHARLS→CLHLS 框架下比较了 FI（Model B：`event ~ fi_full + age`）与 WHO 内在能力（Intrinsic Capacity，IC）五域框架（Model C：`event ~ IC五域 + age`）的跨队列 C-index 变动幅度。结果显示 FI 的 |ΔC| 为 0.052，IC 的 |ΔC| 为 0.095，FI 跨队列变动幅度更小，支持 H5（FI 的跨队列判别稳定性优于 IC）。

然而，此结论须在以下重要限制下解读。第一，**CLHLS 的 IC 测量为二元代理**：受限于原始 CLHLS SAV 文件的实时读取限制，CLHLS 的 IC 五域以 FI 二元项目作为连续测量（握力、步速、峰流速、认知测试分数等）的代理，这可能人为放大 IC 在 CLHLS 中的校准和判别偏差，从而高估 IC 相对于 FI 的跨队列不稳定性。第二，**两模型出发基准不同**：CHARLS 内部 C 分别为 0.7608（FI）和 0.7105（IC），约低 0.05；在内部基准已有差距的前提下，|ΔC| 的直接比较存在一定解读争议。第三，**C-index 在 CLHLS 对两模型均有提升**（FI: 0.7608→0.8131；IC: 0.7105→0.8060），这部分反映了高事件率队列（46.3% vs. 10.2%）对 C 统计量的机械性放大效应，并非真正意义上的迁移性改善，需在解读 |ΔC| 时加以甄别。

综合以上，H5 的当前结果提供了 FI 较 IC 具有更高跨文化判别稳定性的初步支持性证据。完整检验——包括基于 CLHLS 连续 IC 测量的外部验证和更多队列的系统比较——将在第二篇论文中作为主要研究问题展开（D-012）。

## 4.7 临床与公共卫生含义

本研究结果在三个层面具有实践意义。

**全球可用性**：基于 Gateway 协调化数据标准构建的 41-item FI，在涵盖东亚（CHARLS、CLHLS、KLoSA）、北美（HRS）、欧洲（SHARE）和拉美（MHAS）的五种文化情境下均保持 C-index > 0.72 的有临床意义判别能力。这意味着 FI 可作为跨国家可比的衰弱标准化筛查工具，且所需数据均可从已有老龄化调查中获取，无需额外专项测量。

**局部重校准的低门槛与高效益**：L1 截距更新（仅需目标人群四年死亡率的估计值）可将校准性能大幅提升；SHARE 的 IPA 从边际值（0.028）升至实质性水平（0.114），操作门槛极低。对于有条件在目标人群中采集小规模验证数据的机构，L2 斜率校准可进一步改善绝对风险准确性（MHAS IPA: 0.063→0.082），但多数场景下 L1 已足够。

**预测而非干预**：需要强调的是，本模型为纯预测模型，不主张因果关系。FI 是多系统健康状态的综合指标，而非单一可干预危险因素。模型的临床应用应以辅助风险分层为目的，结合医生判断和患者意愿，不宜单独用于治疗决策。

## 4.8 局限性

本研究存在以下主要局限：

（1）**FI 条目跨队列不完全等同**：MHAS 仅有 27/41 个标准可得条目，HRS 的 8 个缺失条目（包括 BMI 和记忆自评）以代理变量替代，dyslipidemia 和 kidney disease 使用测量代理而非诊断变量；这些差异可能影响 FI 量值的跨队列可比性。

（2）**CHARLS 跨波 ID 桥接存在不完全匹配**：基于 householdID 构建规则的桥接，2015 年匹配率 85.5%，2018 年降至 81.3%，约 14–19% 的参与者无法确认随访状态，可能引入选择性失访偏倚。

（3）**教育未纳入主分析**：受协调化数据文件中教育变量可靠性制约，主模型仅含年龄、性别和 FI，未进行教育水平调整，可能低估社会经济地位的混杂效应；此为 preliminary version，后续拟补充。

（4）**CLHLS 结局缺失 22.9%**：尽管 IPCW 敏感性分析证明完整案例结果对信息性删失稳健（ΔC = +0.0008），此缺失率仍高于 10% 的标准警戒线，相关不确定性须明确报告。

（5）**H5 分析的 CLHLS IC 为二元代理**：当前 H5 结论具有探索性；连续 IC 外部验证推迟至第二篇论文。

（6）**亚洲训练池事件率高度不均衡**：CLHLS 事件率（46.3%）远高于 CHARLS（10.2%）和 KLoSA（9.6%），合并训练时 CLHLS 主导均值，可能造成斜率偏移，MHAS 的 L1 后斜率 0.686 印证了这一点。

（7）**非因果框架**：本研究为预测建模，FI 系数不应被解释为可干预的因果效应大小。

（8）**欧洲验证不含英国**：ELSA 因随访死亡记录覆盖范围限制移出主分析（D-013），欧洲验证仅依赖 SHARE，结论不能直接推广至英国老年人群。

## 4.9 优势

本研究具有以下主要优势：（1）**规模与覆盖范围**：跨六国文化情境，60 岁以上参与者逾 75,000 人，60 岁以上死亡事件逾 13,000 例，是当前已知最大规模的跨文化 FI 死亡预测研究之一。（2）**预先注册与结局盲**：全部分析方案在接触任何 FI-结局关联数据之前冻结于 SAP（commit 9bc7b85），并建立完整决策审计链（D-001 至 D-034），满足 TRIPOD+AI 和 PROBAST-AI 的 audit trail 要求。（3）**性能损失归因分解框架**：L0-L3 分层重校准阶梯将模型性能损失分解为可归因的事件率漂移（L1）、斜率漂移（L2）和参数更新（L3）三个层次，为跨文化模型迁移研究提供了可操作的方法学参照。（4）**公开可获取数据与完整可重复性**：全部六个队列数据经官方申请获取，分析代码于 GitHub 公开，具有完整可重复性。
