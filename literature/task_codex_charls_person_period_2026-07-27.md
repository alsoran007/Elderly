## 关键前置：ID 桥接（不做这步后面全错）

CHARLS 的 ID 跨波不一致，**直接匹配重叠为 0**：

```
2011 baseline : 01010410101    (11 位)
2015 及以后    : 094004126001   (12 位)
```

**官方规则**（`bbxleyec.do` 第 1918–1919 行）：

```stata
gen householdID = householdID_w1 + "0"          // 9位户号末尾补"0" -> 10位
gen ID = householdID + substr(ID_w1,-2,2)       // 再接原ID末两位人员码 -> 12位
```

Python 等价写法：
```python
b["pid"] = b["householdid"].astype(str).str.strip() + "0" + b["id"].astype(str).str.strip().str[-2:]
```

**我已实测验证的匹配率（用作断言）：**

| 目标 | 匹配数 | 占基线 |
|---|---|---|
| 2015 `Sample_Infor` | **15,139** | 85.5% |
| 2018 `Sample_Infor` | **14,395** | 81.3% |
| 2020 `Sample_Infor` | **13,734** | 77.6% |
| 2013 `Exit_Interview` | **408** / 431 | 94.7% |

**所有 ID 比较前必须 `.astype(str).str.strip()`**，dtype 不一致会导致静默匹配失败。

## Step 2：构建随访状态

对每个基线个体，逐波判定三分类状态：

| 状态 | 判定 |
|---|---|
| **死亡** | 该波 `died==1`，或（期1）在 `2013/Exit_Interview.dta` 中 |
| **存活** | 该波 `Sample_Infor` 中存在且 `died==0` |
| **失访** | 该波**及之后所有波次**均无记录 |

🔴 **必须避免的错误**：某人 2015 波缺席但 2018 波重新出现（间歇性失访），**不能在 2015 期删失**。判定失访必须检查该个体在**所有后续波次**的出现情况。

**请报告间歇性失访（缺席后又出现）的人数**——这个数字决定 3.4 节的规则是否够用。

## Step 3：转 person-period 长表

每人每个风险期一行：

```
pid | period | period_start | period_end | event | age | sex | ...
----+--------+--------------+------------+-------+-----+-----+
 A  |   1    |     2011     |    2013    |   0   | 65  |  1  |
 A  |   2    |     2013     |    2015    |   1   | 65  |  1  |   <- 死于期2，之后无行
 B  |   1    |     2011     |    2013    |   0   | 71  |  2  |
 B  |   2    |     2013     |    2015    |   0   | 71  |  2  |
 B  |   3    |     2015     |    2018    |   0   | 71  |  2  |   <- 期3后失访，之后无行
```

**规则：**
- 死亡后不再有记录（退出风险集）
- 失访后不再有记录（删失）
- 协变量用**基线值**，各期重复，**不随时间更新**（这是预测模型，不是时变暴露分析）

预期规模：约 45,000–55,000 行。
