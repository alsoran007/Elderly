# Aim 1 report (2026-07-29)

## Scope
CHARLS 2011 age-60+ FI-eligible person-period data were used to develop pooled logistic Model A (age + female + period) and Model B (FI + age + female + period). Model B coefficients were frozen and applied to CLHLS for four-year mortality validation.

## Data and missingness
- CHARLS development: 7546 persons, 14551 person-period rows, 771 events.
- CLHLS external validation: 7095 persons, 3282 events (event rate 46.3%).
- CHARLS complete-case retention: 14551 / 14561 rows.
- CLHLS source missingness: event_4y 23.3%; FI 5.6%; age 0.0%; female 0.0%.
- Education adjustment: not included. Education is absent from the harmonised parquet inputs; this is the preliminary age + female version.

## Model coefficients
Coefficient CSV files in this directory contain the Model A and Model B estimates.

## Internal discrimination
- Model A C-index: 0.7355; Model B C-index: 0.7705; delta C: 0.0351.
- H1 threshold delta C >= 0.02: met.

## CLHLS external validation
- Model B C-index: 0.8389 (bootstrap 95% CI 0.8301-0.8481).
- O:E ratio: 1.2473; calibration intercept: 0.5976; calibration slope: 0.9393.
- Brier score: 0.17509; IPA: 0.2957.
- DCA status: completed.

## Warnings
This is the preliminary no-education-adjustment version. Internal C-index is apparent pooled person-period discrimination; external C-index is person-level.
